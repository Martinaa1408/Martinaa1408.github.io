Thesis project — overview

Development of a Decision Support System for the Assessment and Prediction of Food Contamination Risk

The project transforms a routine compliance archive into an operational risk intelligence tool. Starting from raw LIMS data (~186,000 analytical results across 29 contaminants, 6 regulatory sections, and 30+ food matrix categories), the system reconstructs conformity status, identifies statistically significant risk patterns, extends prediction to pairs with limited observational history via machine learning, and provides a biological characterisation of priority contaminants in the One Health framework. The entire pipeline is governed by Regulation (EU) 2023/915.

Data

Historical records from Neotron's SQL Server LIMS (Jan 2024 – Dec 2025), extracted as .xlsx workbooks via star-schema SQL queries. Regulatory limits are derived dynamically at query time from Reg. EU 2023/915 via a CASE WHEN expression — no static storage — ensuring the system stays aligned as the regulation is updated.

Regulatory framework

Regulation (EU) 2023/915 replaced Reg. EC 1881/2006 in May 2023, consolidating maximum levels across six thematic sections: mycotoxins, plant toxins, heavy metals, POPs/PFAS, process contaminants, nitrates/perchlorates. Its living nature — updated continuously as EFSA adopts new scientific opinions — motivates a dynamic, computational approach rather than any static limit mapping.

Pipeline — four notebooks

A modular, reproducible end-to-end pipeline in Python 3.10, implemented across four Jupyter notebooks. A single SECTION_NUMBER variable controls all paths and parameters, enabling one-click re-execution per regulatory section.

NB1 — Data cleaning & exploratory analysis

SQL extraction from the LIMS star-schema (dbo.ParametriProva + dimension tables). Parsing of the heterogeneous RISULTATO field: administrative strings dropped, not-detected values mapped to 0, left-censored entries dropped.

Descriptive statistics and visualisations (box plots, NC rate bar charts with Wilson intervals, contaminant×month heatmaps). Normality testing via Shapiro–Wilk or Anderson–Darling. Temporal trend analysis via Mann–Kendall applied to STL-deseasonalised monthly NC rates (min. 24 months), with Sen's slope and BH–FDR correction. Multivariate PCA and hierarchical clustering of food matrices.

pandas scipy statsmodels pymannkendall matplotlib · seaborn

NB2 — Statistical inference & risk scoring

Unit of analysis: (contaminant, sub-matrix) pair aggregated over the full study period. Fisher's exact test with BH–FDR correction identifies pairs with significantly elevated NC rates. Wilson 95% confidence intervals quantify estimation uncertainty; interval width is retained as a feature for NB3.

DSS risk thresholds calibrated empirically from the observed distribution: HIGH = P90(nc_rate) = 0.113 · MEDIUM = P75(nc_rate) = 0.028 · LOW below. Output: cross_submatrix_risk.csv with NC rate, CI bounds, and DSS class per pair.

scipy numpy statsmodels

NB3 — Machine learning risk prediction

Binary classification for pairs with insufficient observational history for direct statistical inference. Seven leakage-free features derived from dataset topology (sample size, log-transforms, ordinal size bins, contaminant and sub-matrix label encodings, frequency proxies). nc_rate and n_nc are strictly excluded to prevent data leakage.

Four candidate models — Random Forest, XGBoost, LightGBM, CatBoost — all with native class weighting (no SMOTE). Stratified 5-fold cross-validation, PR-AUC as primary metric. SHAP TreeExplainer for global feature importance and individual-level explanations. Final DSS combines NB2 NC rate with NB3 predicted probability (AND logic for HIGH, OR for MEDIUM).

scikit-learn XGBoost LightGBM CatBoost SHAP

NB4 — Biological in silico analysis

HIGH and MEDIUM contaminants selected from NB3 DSS scores. Chemical–gene interactions retrieved from the Comparative Toxicogenomics Database (CTD) via REST API for Homo sapiens and Mus musculus (direct experimental evidence only, no inferred associations).

GO Biological Process / Molecular Function and KEGG pathway enrichment via gseapy/Enrichr with BH–FDR correction. Tripartite contaminant–gene–pathway network constructed with NetworkX; interactive HTML visualisation via pyvis. Hub genes — connected to two or more distinct contaminants — identified as shared molecular targets and priority signals for RASFF alert communication.

gseapy networkx pyvis
