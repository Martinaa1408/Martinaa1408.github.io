What the unit does

The DWHSANPRI business unit builds and maintains data warehouses and Qlik Cloud dashboards for private healthcare providers. The dashboards turn operational data into KPIs that clinical and administrative staff use day to day.

Healthcare data Data warehouse Qlik Cloud KPI reporting

Training plan and responsibilities

From the apprenticeship training plan.

  • Analysis of users' information needs.
  • Modelling of information needs with the Dimensional Fact Model (DFM).
  • Design of ROLAP databases on MySQL, HP Vertica and PostgreSQL.
  • ETL procedures with Pentaho, Power Query M and Qlik.
  • Data checks through unit tests.
  • Reports and dashboards with Qlik, SAP BusinessObjects and Microsoft BI.
  • Translating KPI definitions into SQL (ANSI-92) queries.
  • Analysis of data patterns for machine learning applications.

Tools

Qlik Cloud SQL (ANSI-92) PostgreSQL MySQL HP Vertica Pentaho Power Query M Microsoft BI SAP BusinessObjects Dimensional Fact Model ROLAP ETL
